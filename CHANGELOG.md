# Changelog

## [0.1.0] - 2026-09-08

### Added

- Deterministic CLI reports for copied shell commands.
- Explicit Bash/POSIX to PowerShell translations for common commands.
- Windows package-manager `.cmd` shim guidance for `npm`, `npx`, `pnpm`, and
  `yarn`.
- Reverse translations for common PowerShell forms.
- JSON and Markdown output for review notes and automation.
- Manual-review status for dynamic evaluation and command substitution.
- Local-only safety boundary and test-first verification record.
